# bayesian-cox-replication
The aim of the project is to replicate the paper "Regression with Frailty in Survival Analysis" by authors C. A. McGilchrist and C. W. Aisbett, entirely within the Bayesian framework, and to contribute our analysis to the posteriorDB framework. 
This replication will be done in Stan, as part of the Bayesian Statistics and Data Analysis course under this [project](https://github.com/MansMeg/BSDA/)
